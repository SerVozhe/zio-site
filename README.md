# ZиО — сайт группы

Одностраничник новокузнецкой альтернативы ZиО (Zero is One): манифест, четыре стража, состав, концерт «Резонанс», новости, релизы, цитаты, артефакты.

Чистый HTML, CSS и ванильный JS. Никаких фреймворков, сборщиков и внешних CDN — все ассеты лежат в `assets/`.

## Как устроено

`content.json` — единственный источник правды. Из него генерируются `index.html` и `site.config.js`, поэтому **`index.html` руками не правят**: следующая сборка его перезапишет.

```
content.json        все тексты, ссылки, дата концерта, списки
index.html          ГЕНЕРИРУЕТСЯ — не редактировать
site.config.js      ГЕНЕРИРУЕТСЯ: ссылки, дата, подписи счётчика
styles.css          визуальная система (карбон, Arial, оранжевый акцент)
app.js              меню, счётчик, scroll-reveal, свет за курсором
tools/render.mjs    шаблоны секций
tools/build.mjs     сборка: content.json → index.html + site.config.js
tools/validate.mjs  проверка контента перед записью
admin/              локальная админка (Node, только 127.0.0.1)
assets/             иконки, OG-картинка, шрифты
```

Дата концерта задаётся один раз — `show.datetime`. День, «5 декабря», год, подпись в меню и бейдж выводятся из неё. В текстах работают токены `{date.badge}`, `{date.long}`, `{date.short}`, `{show}`, `{city}`, `{year}` и другие.

Нумерация разделов (`01…NN`) и пункты меню собираются автоматически. У каждого блока есть флаги `enabled` (показывать на сайте) и `nav` (показывать в меню). Пустые «Новости» и «Релизы» сами исчезают, нумерация не рвётся.

## Сборка

Нужен Node.js 18+.

```bash
node tools/build.mjs
```

## Админка

Локальный редактор контента — работает только на своём компьютере, на хостинг не уезжает.

```bash
node admin/server.mjs
```

Открыть http://127.0.0.1:8787/admin. Первый запуск просит придумать пароль: он хранится локально как scrypt-хеш в `admin/auth.json` (в репозиторий не попадает, см. `.gitignore`).

Кнопки: **Сохранить** (Ctrl+S) — валидация, бэкап в `admin/backups/`, атомарная запись и пересборка; **Собрать** — пересборка без правок; **ZIP** — архив только файлов сайта, без админки и `content.json`; **Копия / Импорт** — выгрузка и восстановление `content.json`. Загрузка картинок идёт в `assets/img/uploads/` (png, jpg, webp, до 10 МБ).

## Публикация

Хостинг статический. Достаточно залить `index.html`, `site.config.js`, `styles.css`, `app.js` и папку `assets/` — либо взять готовый ZIP из админки. Node на хостинге не нужен.
